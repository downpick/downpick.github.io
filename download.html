What you'll need

Windows 10 or later, macOS 12 or later, or a recent Linux desktop. Around 250 MB of disk.

First launch

You'll set a master password for the vault. There is no recovery — write it down somewhere safe.

The builds are unsigned

macOS blocks the first launch — right-click Downpick and choose Open. On Windows, SmartScreen needs More info → Run anyway.

Rather build it yourself?

The source is on GitHub. Node 20 and two npm installs is the whole story.
